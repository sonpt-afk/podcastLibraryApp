# Ebook-only scope; listener features removed

The product makes exactly one deliverable, an Ebook, and the repo's original listener features (favorites, ratings, hashtags, the Zustand/localStorage store, Podbean scraping) are deleted rather than kept alongside. The original plan promised five product types (ebook, email course, social posts, templates, blog); each needs its own generation, validation, and export surface, and no Creator has yet shown they will pay for the first. New product types need new evidence from the Phase 1 gate (see `docs/SPEC.md`), not a reopened scope discussion.
